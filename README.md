# 😷 Face Mask Detection Using Deep Learning (CNN)

An AI-powered **Face Mask Detection System** built using **Convolutional Neural Networks (CNN)** and deployed with **Streamlit**.  
The model classifies images into:

- 😷 Mask
- ❌ No Mask

This project demonstrates how Computer Vision and Deep Learning can be used for real-world safety applications.

---

## ✨ Features

✔ Upload images (JPG / PNG / JPEG)  
✔ Real-time prediction (Mask / No Mask)  
✔ Confidence-based classification  
✔ Clean Streamlit UI  
✔ Sidebar navigation (Home / Project Journey)  
✔ Background image styling (modern UI)  
✔ Interactive user experience  

---

## 🧠 Model Overview

- Model Type: CNN (Convolutional Neural Network)
- Framework: TensorFlow / Keras
- Input Size: 200 × 200 images
- Classes:
  - With Mask 😷
  - Without Mask ❌

The model outputs a probability score which is used to determine the final class prediction.

---

## ⚙️ How It Works

1. User uploads an image  
2. Image is resized to 200×200 pixels  
3. Image is converted to array and normalized  
4. CNN model predicts output probability  
5. Confidence score determines final class  
6. Result is displayed in Streamlit UI
